# 数据与权限

- 数据库、课程资料、浏览器配置、企微数据库副本和模型缓存均保存在用户本机。
- 不提供开发者托管的同步服务，不默认发送遥测。
- Canvas 与空中课堂使用独立浏览器配置，用户自行登录；不能打包或共享该目录。
- 企微采集会读取已选择账号的本地数据库副本以识别身份和发现会话，并保留本地证据。只有用户确认绑定的课程会话进入课程视图。原客户端数据库只读。
- 企微密钥由 Windows DPAPI 加密，运行目录限制当前用户与 SYSTEM；不会通过 API 返回密钥。不启用客户端注入、网络拦截或鼠标键盘自动下载。
- 本地 Ollama 不把课堂文本发送至开发者服务。用户选择云端 API 后，待处理课堂文本或课表截图会发往用户配置的服务商，费用与处理规则由该服务商决定。
- 普通设置不含 API Key；Key 单独用 Windows DPAPI 保存。不要分享整个应用数据目录。
- 卸载默认保留资料。备份、日志和报告可能含个人内容，分享诊断前应自行脱敏。

当前仅针对本人账号、本机使用。开源代码不意味着获准复制或公开学校资料与他人聊天。
