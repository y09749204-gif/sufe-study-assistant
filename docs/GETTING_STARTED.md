# 首次启动与设置

首次启动自动进入六步向导。课表草稿和步骤保存在本应用的数据目录，界面显示“草稿已保存到本机”后可以关闭，下次继续。尚未确认的草稿不生成课程或日历；API Key 不进入草稿。

1. **欢迎与检查**：确认独立数据库已连接。未安装 Chrome／Edge 时仍可继续手动课表，学校登录稍后配置。
2. **资料目录**：保留默认目录或选择自己的位置，包括 C 盘。点击检查空间与写入权限；数据库与凭据位置由程序管理。已有资料的目录不直接更换。
3. **学期与课表**：填写第一教学周的周一、教学周数（节次时间已按上财统一内置，无需配置）。手动添加课程、导入 CSV 或识别截图；检查星期和单双周，点击“校验并预览”，核对后“确认导入”。截图识别需先在第 5 步保存看图模型，再返回这里。
4. **连接学校平台**：登录 Canvas 后关闭登录窗口，读取身份、刷新并核对账号后绑定。空中课堂登录后关闭窗口，点击登录检查，再刷新状态。当前空中课堂检查确认可访问参与课程页面，不自动核验姓名，请自行核对登录账号。两个平台均可跳过。
5. **学习功能**：默认不使用 AI。可以选择本机 Ollama 或自己的兼容 API，文字与看图模型分别填写。云端发送需明确同意；保存并测试文字模型不会自动证明看图能力。选择默认文本／图文回放模式。Whisper 和 LibreOffice 后续按需安装。
6. **准备完成**：查看实际课程数、日历数及连接状态，按需同步。回放可以勾选课程加入队列；已启动／已排队不等于成功。完成后进入工作台。

企微在工作台的“连接”中配置：选择本机账号、核验姓名和组织、同步后确认课程群。未缓存附件仍需先在企微手动下载。

需要重新查看向导时，打开“设置 → 重新打开设置向导”。重新进入不会清空已有课程，也不会自动重复导入草稿。AI 配置请点保存后再离开；未保存的密钥不会自动恢复。
